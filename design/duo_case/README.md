## Making and assembly
回收标志现为一个融合实体，平底朝下制作；底托Z0–1.0，六段新图案凸箭头Z1.0–2.0，整体无需粘合箭头小件。模型为白色；需要黑色箭头时，可在Z1.0换色。三处自然细缝约0.279、0.270、0.280 mm，按图保留，工艺可辨识度先做小样；中心和箭头间有连续白底。分件平底与背壳0.1深中央浅凹及外围总深0.2环线对位，先做TPU/PETG薄涂胶小样并均匀压合。名义无额外胶厚和侧隙，实际胶与制造误差计入试配；嵌入0.1后名义凸出原背面1.9。
默认背盖TPU95A，护轴片柔性TPU，面盖/饭盒面片/内盖板/镜头圈PETG。没有指定层高、打印机配置或G-code。护轴片按0.76 mm等厚模型制作，平底朝下，先做厚度与滑槽小样；材料厚度、收缩和弯曲疲劳需实测。
饭盒阶梯、边框、凹面及凸字在独立面片中一体制作，面盖单独制作。面片平底朝下、凸字朝上；用0.1深定位细线在面盖外侧对位，表面清洁后薄涂兼容PETG的胶，均匀压合固定至固化。先试胶种、涂量、夹持与接缝；模型未加胶层厚度，不把实际粘合后高度当作零公差。宋体细笔画、0.5高凸字、0.8留边及0.2口沿倒角先做小样，确认打印分辨率和清理方式；字顶低于框顶0.5，避免后处理磨损细笔画。基础面盖外侧除细线外为平面，但右侧下伸磁吸扣需结合切片选择朝向和支撑；定位线0.1深、0.3宽必须先验证实际工艺可辨识度，勿被首层压扁或胶覆盖后再尝试找线。支撑不得损伤配合面、磁铁槽或滑道。内盖贴片平整装配背面朝下、凹面朝上制作，先做0.2深浅凹及1.2留边小样，检查中央1.0 mm薄区与外圈1.2 mm厚边的平整度；背盖外面朝下时须检查0.1深定位浅凹是否被首层压平；扣边悬伸先试样，清毛刺而不磨薄。
原护轴片在闭合参考中与内盖板有0.16 mm干涉，是此前用户接受的暂留例外；不是压配。解除前不得强行装配或试滑。解除后先双槽套桩，内盖板上下及右侧固定承台施胶留0.2，左滑动腔及铰链口不涂胶；固化后手动试滑，再胶接背盖固定端留0.2，115.3宽护轴两端各留0.2，胶不可挤入端隙。
