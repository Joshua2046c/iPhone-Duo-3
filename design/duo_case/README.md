# iPhone duo 饭盒造型护轴手机壳

## Design intent
六件结构：背盖、护轴片、平整内盖板、带定位线面盖、摄像头保护圈、独立饭盒粘合面片。全部正面和内侧装饰嵌件、原一体内侧浮雕、正面装饰浅槽及背面精灵球凹刻取消。护轴片仍独立展平展示在壳右侧，其余为闭合位置。
饭盒凸起从原盖面世界Z18.85处拆成独立平底面片，与基础面盖粘合。面盖在76×113/R12底轮廓中心线上刻一圈定位细线，默认宽0.25、用户指定深0.08，槽底Z18.77。两片按名义贴合建模，未额外预留胶层；真实胶厚计入总高。面片局部底Z0、摆放Z18.85，最高世界Z22.7，总外形与分件前一致。
用户饭盒图片是外观参考，不是尺寸图。整体饭盒浮雕高度按用户要求降低30%：原平台3.5×0.7=2.45，原中心附加2×0.7=1.4，最高3.85；基准为上盖原外平面Z18.85。平台世界Z21.3、中心框顶Z22.7。外圈阶梯每侧外扩1 mm为默认，根部76×113/R12、名义顶74×111/R11；条纹框和中心框平面位置与尺寸保持。外圈及28条短筋纹相对平台高0.56。
中央框顶面内偏0.8 mm为圆角矩形上口56.12×93.12/R5.06；整圈新增默认C0.2×45°倒角。直壁先向内退0.2、轮廓55.72×92.72/R4.86，使倒角后顶面水平留边仍为0.8；凹深1、平底世界Z21.7。0.8从实际倒圆后的中央平面外边量到凹口边，留边连续等宽。中央宋体凸字“降解餐盒”，默认字号18 mm、从凹底凸0.5，字顶世界Z22.2，低于框顶0.5。按截图横向阅读，模型旋转90°排字，磁吸卡扣向下横放时正读。
字体使用已验证的macOS Songti SC（Songti.ttc）REGULAR，STEP中为实体字形；源重新生成需系统安装此字体，未打包字体文件。实际字形包络17.136035×70.217988 mm，居中，全部位于凹面内。造型仍竖向、右侧原磁吸扣，颜色沿用；上盖内面和外围保持平整。用户指定30%、凹深1、留边0.8、宋体文字；阶梯外扩1、字号18、字凸0.5为默认。

## Making and assembly
默认背盖TPU95A，护轴片柔性TPU，面盖/饭盒面片/内盖板/镜头圈PETG。没有指定层高、打印机配置或G-code。护轴片按0.76 mm等厚模型制作，平底朝下，先做厚度与滑槽小样；材料厚度、收缩和弯曲疲劳需实测。
饭盒阶梯、边框、凹面及凸字在独立面片中一体制作，面盖单独制作。面片平底朝下、凸字朝上；用0.08深定位细线在面盖外侧对位，表面清洁后薄涂兼容PETG的胶，均匀压合固定至固化。先试胶种、涂量、夹持与接缝；模型未加胶层厚度，不把实际粘合后高度当作零公差。宋体细笔画、0.5高凸字、0.8留边及0.2口沿倒角先做小样，确认打印分辨率和清理方式；字顶低于框顶0.5，避免后处理磨损细笔画。基础面盖外侧除细线外为平面，但右侧下伸磁吸扣需结合切片选择朝向和支撑；定位线0.08深、0.25宽必须先验证实际工艺可辨识度，勿被首层压扁或胶覆盖后再尝试找线。支撑不得损伤配合面、磁铁槽或滑道。内盖板平面朝下，检查1.2 mm薄板平整度；背盖外面朝下时须检查0.3深回收凹刻是否被首层封住；扣边悬伸先试样，清毛刺而不磨薄。
原护轴片在闭合参考中与内盖板有0.16 mm干涉，是此前用户接受的暂留例外；不是压配。解除前不得强行装配或试滑。解除后先双槽套桩，内盖板上下及右侧固定承台施胶留0.2，左滑动腔及铰链口不涂胶；固化后手动试滑，再胶接背盖固定端留0.2，115.3宽护轴两端各留0.2，胶不可挤入端隙。
镜头圈在未装手机时先干配，再外翼均匀施胶留0.15，镜孔内不进胶；拆卸先取手机并解除胶接，从内侧均匀推下，不以镜头作支点。相机内侧弧形避让不能用直接外扩通孔代替。
磁环和尾磁铁与胶总厚度配0.99槽深，侧磁铁与胶配1.03，先核对极性和实物尺寸。空壳低力试配0.17相对间隙，不能让磁铁凸出端面。先用尺寸样块检查等效单边0.205余量、扣边0.7/0.6的保持力，再试机；取放从自由侧低力松开，不以屏幕或镜头为支点。整面盖板沿台阶胶接，靠滑道胶边较窄，需试拉脱和胶量校准。
尚无打印、粘接、实机充电对中、跌落或疲劳试验，照片位置与圆角不是机械尺寸认证。
