# iPhone duo 饭盒造型护轴手机壳

## 产品与外观
纯机械护轴手机壳，无电路板或电子模块。六件组成：背盖、柔性护轴片、整面内盖板、带定位线面盖、独立摄像头保护圈、饭盒粘合面片。取消所有装饰小件及其定位浅槽、上盖内侧一体浮雕、正面折线与胶囊凹槽、背面精灵球凹刻。
独立饭盒面片粘在面盖正面，形成参考图片中的饭盒凸起造型，饭盒竖向、左侧铰链、开口朝右；现有右侧磁吸卡扣充当饭盒扣。上盖内侧与浮雕外围平整；背壳下方设可回收标志凹刻。内部护轴腔、磁铁功能凹槽及相机保护结构保留。
整个饭盒浮雕高度减薄30%：平台高2.45 mm，中心框再高1.4，最高凸高3.85。中央做圆角矩形凹面，深1 mm，与中央框实际顶面边缘等距留0.8；凹面口沿整圈做默认C0.2×45°倒角，直壁内退0.2以保留顶面0.8 mm平边。凹面原标注尺寸指倒角上口，直壁轮廓55.72×92.72。凹面中央增加宋体凸字“降解餐盒”。外圈阶梯向外延伸，默认每侧1 mm，根部76×113、名义台顶74×111。条纹框和中央框平面尺寸保持；中央凹面56.12×93.12、角R5.06。世界平台面Z21.3、中心框顶22.7、凹底21.7。
文字采用系统Songti SC宋体，默认字号18 mm、凹底上凸0.5 mm，字顶Z22.2，低于中心框0.5；按标记横向排布，磁吸卡扣朝下横放时正读。外圈和28条筋纹在台面上高0.56，筋宽2.4、间距9。仅面盖外侧有饭盒浮雕，沿用原颜色、右侧磁吸扣、平整内侧和壳外围。每侧外扩1、字号18与字凸0.5为可调整默认；减薄30%、凹深1、留边0.8及宋体文字来自用户。
饭盒凸起在原盖面Z18.85处分成独立面片和平面面盖，粘合组装。面盖按面片76×113/R12底轮廓留一圈0.08 mm深定位细线，默认宽0.25 mm，槽底Z18.77。两片名义贴合，无额外胶厚预留；实际胶厚计入成品总高。背壳下方严格按上传参考三箭头轮廓凹刻0.3 mm，三处转折细缝不连接，六段带面按参考分开，箭头之间的大空隙保留，默认宽18、高17.755656、中心(2.05,-45)，底Z-0.7；该区域至内侧尾磁槽最小背衬2.11。

护轴片展平48.356135×115.3，全片统一0.76 mm等厚；两侧均为平面，取消中间下凹与全部厚薄过渡，展平底面Z0、顶面Z0.76。双槽18.479587×8.4、四角R2.1、Y±25，槽心距弯端0.849794；自由端外角R3、左端封边16.34。胶端5、自由段16.926548、滑尾26.429587。
前盖基础厚4，深收纳腔70.1×115.7、深2.6，远端两个平面角R3；无装饰浅槽后的基础顶皮厚1.4。双胶囊桩宽3.2×纵长7.4、中心X-31.720413/Y±25。整面内盖板80.9×118.6×1.2，两面平整，外露面Z14.85、固定面Z16.05；台阶座81.3×119深1.4、单边间隙0.2、固定承台胶层0.2。转轴侧连续窄边取消，仅两端局部台阶齐平；滑片通道不得涂胶。背盖胶槽5.3×115.7深1.2，护轴每端间隙0.2。

## 制作默认与交付验收
背盖TPU95A、护轴片0.76 mm等厚柔性TPU原型，面盖、饭盒面片、内盖板和镜头圈PETG；没有指定打印机、层高或切片配置。制作需先验证薄片、扣边、胶接、磁铁槽和浮雕小样。
交付六个独立部件的参数化STEP试配模型。验收包括竖向饭盒外观、右侧既有扣位、浮雕只向上盖外侧凸出、内盖板平整、背部回收凹刻及面盖定位线、各部件有效且连续，以及静态间隙。真实机身适配、无线充电对中、磁力、胶接保持力及连续开合寿命需实物确认。未授权改变的尺寸、功能要求与结构细节以结构化需求和约束为准。
