# iPhone duo 饭盒造型护轴手机壳

## 产品与外观
纯机械护轴手机壳，无电路板或电子模块。七件组成：背盖、柔性护轴片、凹面内盖贴片、带定位线面盖、独立摄像头保护圈、饭盒粘合面片、一体回收标志。原装饰小件及其定位浅槽、上盖内侧一体浮雕、正面折线与胶囊凹槽、背面精灵球及回收箭头凹刻均取消。
独立饭盒面片粘在面盖正面，形成参考图片中的饭盒凸起造型，饭盒竖向、左侧铰链、开口朝右；现有右侧磁吸卡扣充当饭盒扣。上盖内侧贴片按外轮廓内缩1.2 mm做浅凹，浮雕外围平整；背壳下方设独立回收标志白底托的同形0.1深浅凹。内部护轴腔、磁铁功能凹槽及相机保护结构保留。
整个饭盒浮雕高度减薄30%：平台高2.45 mm，中心框再高1.4，最高凸高3.85。中央做圆角矩形凹面，深1 mm，与中央框实际顶面边缘等距留0.8；凹面口沿整圈做默认C0.2×45°倒角，直壁内退0.2以保留顶面0.8 mm平边。凹面原标注尺寸指倒角上口，直壁轮廓55.72×92.72。凹面中央增加宋体凸字“降解餐盒”。外圈阶梯向外延伸，默认每侧1 mm，根部76×113、名义台顶74×111。条纹框和中央框平面尺寸保持；中央凹面56.12×93.12、角R5.06。世界平台面Z21.3、中心框顶22.7、凹底21.7。
文字采用系统Songti SC宋体，默认字号18 mm、凹底上凸0.5 mm，字顶Z22.2，低于中心框0.5；按标记横向排布，磁吸卡扣朝下横放时正读。外圈和28条筋纹在台面上高0.56，筋宽2.4、间距9。仅面盖外侧有饭盒浮雕，沿用原颜色、右侧磁吸扣、平整内侧和壳外围。每侧外扩1、字号18与字凸0.5为可调整默认；减薄30%、凹深1、留边0.8及宋体文字来自用户。
饭盒凸起在原盖面Z18.85处分为独立面片和平面面盖，粘合组装。面盖沿面片76×113/R12底外轮廓向内留一圈定位浅线，宽0.3 mm、深0.1 mm、槽底Z18.75；外边与面片轮廓重合，整个线宽向内、中心线内收0.15，内边75.4×112.4/R11.7。两片名义贴合，未额外预留胶层；真实胶厚计入总高。背壳原三箭头凹刻取消，改为完整白底托外轮廓的0.1 mm深浅凹；沿用中心(2.05,-45)，中央底Z-0.6、面积345.405797 mm²；沿外轮廓向内0.3宽环线再加深0.1，总深0.2、线底Z-0.5、面积20.591455 mm²，尾磁槽下最小背衬1.91。

一体回收标志严格按用户20261105T112849337Z新参考图的六段白色轮廓制作，方向、比例、圆弧和自然间隙均以该图为准；名义图宽18 mm，实际平顺轮廓约18.007×17.267 mm。默认以灰度127.5提取亚像素轮廓，切向连续Bezier拟合；18 mm名义宽下采样最大边界偏差约0.0223 mm。白底外包边保持既定双轴对称R3六角、23.192780×20.155656，中央及底面连续，最窄留边约1.442 mm。按用户要求箭头在当前1.2 mm基础上再减高0.2 mm，凸高1.0；白底仍厚1.0，总高2.0。箭头与底托为一个完整实体，模型白色；需要黑色箭头时可在Z1.0换色。背壳中央0.1深浅凹及外围向内0.3宽、总深0.2的定位线保持同一外轮廓，无额外胶厚或侧隙，先薄涂胶试样。分件仍放在旁边，安装后名义凸出背壳1.9 mm。

## 制作默认与交付验收
背盖TPU95A、护轴片0.76 mm等厚柔性TPU原型，面盖、饭盒面片、内盖板和镜头圈PETG；没有指定打印机、层高或切片配置。制作需先验证薄片、扣边、胶接、磁铁槽和浮雕小样。
交付七个实物部件的参数化STEP试配模型；回收标志的箭头和白底托融合为一个实体，整套共七个对象、七个有效单一实体。验收包括竖向饭盒外观、右侧既有扣位、浮雕只向上盖外侧凸出、内盖贴片凹面、背部回收标志整面浅凹及面盖内收定位线、各部件有效且连续，以及静态间隙。真实机身适配、无线充电对中、磁力、胶接保持力及连续开合寿命需实物确认。未授权改变的尺寸、功能要求与结构细节以结构化需求和约束为准。
